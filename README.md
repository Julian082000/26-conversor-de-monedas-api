# API REST — Conversor de Monedas Offline-First

Backend serverless en **Next.js + TypeScript** desplegado en **Vercel** (`https://26-conversor-de-monedas-api.vercel.app`) con autenticación JWT de **Firebase**, persistencia en **Cloud Firestore** aislada por usuario y consulta de tasas de cambio e historial de 7 días.

## Comandos de Verificación y Compilación
- `npm run typecheck` — Validación estricta de TypeScript
- `npm run lint` — Análisis estático ESLint (0 advertencias)
- `npm test` — Pruebas unitarias de seguridad y validación (Vitest)
- `npm run build` — Compilación de producción Next.js
